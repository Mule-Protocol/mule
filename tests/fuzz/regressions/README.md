# Régressions de fuzzing

Chaque défaut confirmé du programme doit ajouter ici le JSON de sa séquence réduite (tableau de commandes), nommé d'après le défaut. Le pilote rejoue tous les fichiers .json avant les entrées aléatoires. Ce dossier ne contient encore aucune séquence prétendue issue d'un défaut : ne pas inventer de découverte.
